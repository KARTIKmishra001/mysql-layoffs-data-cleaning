# Dataset

`layoffs_raw.csv` is the CSV supplied for this project. It contains 2,361 rows and 9 columns, with reported dates spanning 2020–2023.

Before publishing this CSV publicly, verify that the original dataset's license and source terms permit redistribution. If not, remove the CSV from the repository and update the main README with the source/link and instructions for obtaining it lawfully.

The data is included unchanged as the raw input; the SQL scripts create separate staging tables for cleaning. Do not edit historical dates to make the dataset appear newer.
